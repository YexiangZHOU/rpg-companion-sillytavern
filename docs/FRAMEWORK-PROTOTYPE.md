# 通用框架第一阶段：数据内核与可交互原型

本文件为第一阶段历史结果。第二阶段本地聊天接入进度与当前边界见[接入说明](FRAMEWORK-INTEGRATION.md)，下文“尚未接入”指第一阶段结束时。

## 已实现

- state.mjs：游戏定义和值分离，对象/组别/字段稳定编号；number/text/boolean/choice/resource/tags/collection 控件类型。新结构为空，没有任何默认游戏字段。
- 模型事务可初始化、创建组别和字段、改名/移组、改值、更新条目、归档/恢复。允许增加集合列，原列编号/类型须保留。仅玩家能控制结构锁/数值锁；继承锁保护子项。手动编辑可修改模型被锁定的内容。
- 对应 revision/id 的原子事务，非法操作整批拒绝；最近32项事务保留完整规范化内容用于幂等比对；更早事务的旧基准版本仍会被拒绝。未知为null，与零/false/空列表不同。
- protocol.mjs：模型说明及 rpg-framework 文本协议；跳过代码/引用示例，解析原始 JSON 保留字段中的反引号/标签，成功提交后才移除相应结构块。
- snapshots.mjs：纯快照助手适配ST形状的回复/swipe；结构/值/锁同时保存，精确回复文字匹配，编辑/删除/切换恢复正确的祖先记录。不会自己调用ST的保存接口。
- panel.mjs/panel.css：动态对象/组别导航、重要字段摘要、数值/资源/未知展示、条目详情、手动编辑、改名/摘要设置、组级锁、条目归档与恢复。独立内容滚动、组别滚动位置/展开状态/键盘焦点保持，中文/英文操作字典。
- 四种合成模型输出展示不同分类和数据：修仙、太空、经营、纯叙事。它们只在examples目录，运行框架不导入或依赖游戏样例。
- 独立HTML预览：可粘贴任意符合协议的初始化/更新。预览按案例独立保存浏览器状态及最多24个分支快照，所有数据为本地合成样例。

## 运行与验证

无需新增依赖：npm run test:framework / npm run preview:framework。构建脚本也可传目标路径生成单HTML，直接浏览器打开，不需服务。

本轮41项数据/协议/快照测试通过，51项本地浏览器交互/布局检查通过。覆写脚本或导出测试数据不构成真实模型/生产验收。

## 本阶段边界

扩展index、现有生成器/持久化/渲染入口尚未引入这些模块，线上和旧聊天完全不受影响。本轮不推送或部署。模型初始化目前以合成文本/手动粘贴验证，未调用真实LLM。

动态组别与字段已可工作，但未实现任意脚本、计算字段、嵌套集合、规则引擎、全套玩家结构编辑器或自动场景跟踪。字段类型/对象归属不会在模型更新中被改写。结构/数值大小有技术限额，模型不决定这些限额。

头像暂用首字占位，左场景为手绘色块示意；正式头像/场景图、NPC面板及原遭遇窗口读取将在后续接入。原型不是完整游戏客户端。
